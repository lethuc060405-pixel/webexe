# 🌸 Tích Cơ - Stickers Việt Nam (Landing Page)

Website landing page giới thiệu và bán các bộ sản phẩm sticker nghệ thuật mang đậm bản sắc văn hóa Việt Nam, được phát triển theo đúng chuẩn thiết kế UI/UX từ bản mẫu thiết kế.

## 📁 Cấu trúc thư mục

```text
EXE101Thuc/
├── index.html                   # Giao diện chính của Landing Page
├── start.sh                     # Script khởi chạy web server nhanh cho máy Mac
├── HUONG_DAN_SU_DUNG.md         # Hướng dẫn chi tiết cho người mới bắt đầu
├── css/
│   └── style.css                # Toàn bộ CSS giao diện, animations và responsive
├── js/
│   └── app.js                   # Xử lý tương tác, giỏ hàng, đặt hàng, tìm kiếm
└── assets/
    ├── icons/                   # Vector logo và biểu tượng SVG
    │   └── logo.svg
    └── images/                  # Hình ảnh cắt từ bản thiết kế
        ├── hero_journal.jpg
        ├── shop_featured_vnqh.jpg
        ├── card_vn_quehuong.jpg
        ├── card_amthuc.jpg
        ├── card_vanhoa.jpg
        ├── card_doisong.jpg
        ├── card_thiennhien.jpg
        ├── card_setchude.jpg
        ├── about_water_landscape.jpg
        └── contact_temple_art.jpg
```

## 🚀 Khởi chạy nhanh

- **Cách 1**: Nhấp đúp chuột vào file `index.html` để mở trực tiếp trong trình duyệt.
- **Cách 2**: Chạy lệnh `./start.sh` trong Terminal để khởi động local web server tại `http://localhost:8000`.
